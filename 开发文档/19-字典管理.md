# 字典管理

`admin-base-core` 的 `CommonStatus` 固定启禁用语义：数据库 `1/0`，接口 `ENABLED/DISABLED`。动态业务选项由 `sys_dict` 和 `sys_dict_item` 保存，两者均支持启禁用。禁用的字典或字典项不会出现在选项接口中。

Flyway `V12__system_dictionary.sql` 创建字典表、唯一约束、字典管理菜单和 `system:dict:*` 权限。`V14__add_dictionary_item_color.sql` 为字典项新增可空的 `item_color`，并给内置启禁用项分别设置成功色与错误色。内置 `common_status` 类型及其 `ENABLED`、`DISABLED` 项只读；服务端拒绝修改和删除，前端将相应操作置灰。字典编码创建后不可修改；字典项值创建后不可修改。删除字典前须先删除所有字典项。

字典类型和字典项的新增、修改、删除均记录操作日志；目标类型分别为 `DICT`、`DICT_ITEM`。审计写入与业务写入共用事务，审计失败时回滚业务操作。内置字典的拒绝操作不记录成功日志。

字典项颜色 `itemColor` 可留空或清空；空值在列表中不显示彩色标签。前端通过 Vben Form 自定义色点组件选择预设颜色，提交 `#RRGGBB`；服务端仅接受六位十六进制颜色，并继续兼容已有的 `success`、`warning`、`error`、`processing` 语义色。字典项列表和 `GET /system/dict-options/{code}` 都返回该字段，业务页面可按需展示颜色，不影响字典项的实际取值。

| 接口 | 用途 | 权限 |
| --- | --- | --- |
| `GET /system/dicts?page=&pageSize=&dictCode=&dictName=&status=` | 字典类型分页查询 | `system:dict:list` |
| `GET /system/dicts/{dictId}` | 字典详情 | `system:dict:view` |
| `POST /system/dicts` | 新增字典 | `system:dict:create` |
| `PUT /system/dicts/{dictId}` | 修改字典 | `system:dict:update` |
| `DELETE /system/dicts/{dictId}` | 删除空字典 | `system:dict:delete` |
| `GET /system/dicts/{dictId}/items?page=&pageSize=&itemLabel=&status=` | 字典项分页查询 | `system:dict:view` |
| `POST /system/dicts/{dictId}/items` | 新增字典项 | `system:dict:create` |
| `PUT /system/dicts/{dictId}/items/{itemId}` | 修改字典项 | `system:dict:update` |
| `DELETE /system/dicts/{dictId}/items/{itemId}` | 删除字典项 | `system:dict:delete` |
| `GET /system/dict-options/{code}` | 已启用选项 | 已登录用户 |

两个管理列表均由后端先筛选、再分页，返回 `{ items, total }`；`page` 默认 1，`pageSize` 默认 20，最大 100。字典项按排序号和 ID 排序；已启用选项接口保持完整列表，不受管理分页影响。管理响应使用独立 `DictVO`、`ItemVO`，实体仅对应表结构；时间字段采用 `LocalDateTime` 与统一 `yyyy-MM-dd HH:mm:ss` 格式。当前无业务下拉框接入动态字典；后续新增业务选项时通过 `getDictOptions(code)` 读取。
