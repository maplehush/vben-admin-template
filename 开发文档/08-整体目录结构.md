# 整体目录结构

```text
vben-admin-template/
├── README.md                 # 项目入口与构建说明
├── .gitignore                # 统一排除本地产物与密钥
├── frontend/                  # Vben Admin 前端，页面、API 封装与表单
├── backend/                   # Java 21 + Spring Boot 模块化单体
│   ├── admin-base-core/       # 公共契约与时间工具
│   ├── admin-module-system/
│   │   ├── admin-system-api/  # 预留跨模块契约
│   │   ├── admin-system-biz/  # 系统管理业务实现
│   │   └── admin-system-start/ # 唯一启动模块
│   ├── schema/                # Flyway 唯一迁移源
│   └── pom.xml
└── 开发文档/                 # 设计、接口契约和联调说明
    └── design/              # 品牌素材、预览图和生成脚本
```

前端与后端独立构建；后端所有模块最终打包为一个可运行 JAR。后端的详细包结构、模块边界和 `biz` 命名说明见[详细项目目录结构](07-详细项目目录结构.md)。
