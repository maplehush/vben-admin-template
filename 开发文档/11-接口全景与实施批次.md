# 后端接口全景与实施批次

此前的[核心接口设计](10-核心接口设计.md)覆盖 Vben 登录闭环及图片验证码的 **7 个接口**，不是模板的全部 API。本文件列出模板目标接口面及当前实现状态。路径均为 Spring Boot 逻辑路径，浏览器通过同源 `/api` 前缀访问。管理接口的 ID 使用十进制字符串。

## 批次与状态

| 批次 | 范围 | 当前状态 |
|---|---|---|
| A：登录闭环 | 图片验证码、登录、刷新、退出、当前用户、权限码、动态菜单 | 后端已实现；另有首次改密接口 |
| B：权限管理 | 用户、角色、部门、资源、角色授权、数据范围 | 后端接口与前端管理页面已实现；浏览器完整联调待完成 |
| C：运行管理 | 会话、登录日志、操作日志 | 本人会话、管理员会话和两类日志查询接口及页面已实现；浏览器完整联调待完成 |
| D：扩展能力 | 字典、参数、文件、仪表盘 | 字典管理和图片上传已实现；系统参数、通用文件管理与真实业务仪表盘待业务需求确定 |

## A：登录与当前用户

| 方法与路径 | 用途 | 鉴权 |
|---|---|---|
| `GET /auth/captcha` | 获取一次性图片验证码 | 匿名；独立限流 |
| `POST /auth/login` | 验证验证码及账号密码并创建会话 | 匿名；按账号及 IP 分别限流 |
| `POST /auth/refresh` | Cookie 刷新并轮换令牌 | Refresh Cookie |
| `POST /auth/logout` | 退出并撤销当前会话 | Refresh Cookie，可幂等 |
| `GET /user/info` | 当前用户信息 | 已登录 |
| `GET /auth/codes` | 当前用户权限码 | 已登录 |
| `GET /menu/all` | 当前用户动态菜单 | 已登录 |

这七个接口的字段、错误码、Cookie 规则及示例见[核心接口设计](10-核心接口设计.md)。模板不开放公开注册、短信、扫码或第三方登录；找回流程落地前不展示“忘记密码”入口。

## B：用户管理

| 方法与路径 | 用途 | 权限码 |
|---|---|---|
| `GET /system/users` | 分页、条件查询用户 | `system:user:list` |
| `GET /system/users/{userId}` | 用户详情 | `system:user:view` |
| `POST /system/users` | 创建用户 | `system:user:create` |
| `PUT /system/users/{userId}` | 编辑基础资料 | `system:user:update` |
| `PUT /system/users/{userId}/status` | 启用或停用 | `system:user:status` |
| `PUT /system/users/{userId}/roles` | 原子替换用户角色 | `system:user:grant` |
| `POST /system/users/{userId}/reset-password` | 管理员提交临时密码并撤销会话 | `system:user:reset-password` |
| `PUT /user/profile` | 修改本人资料 | 已登录，仅本人 |
| `PUT /user/password` | 修改本人密码 | 已登录，校验旧密码 |

第一版以停用替代物理删除用户，以保留日志和会话关联。重置密码由管理员在请求中提交 `temporaryPassword`，通过线下受控渠道交付，不在普通 API 响应或日志中回显。仅系统超级管理员可授予员工普通角色或在创建用户时指定非空普通角色集合；`super_admin` 只由首次初始化流程绑定，用户管理接口不能授予它或替换系统账号角色。普通管理员不可修改、停用或重置拥有 `super_admin` 角色的用户。`GET /system/users` 使用 `page`、`pageSize` 和白名单筛选参数，响应 `{items,total}`。

## B：角色与授权

| 方法与路径 | 用途 | 权限码 |
|---|---|---|
| `GET /system/roles` | 分页查询角色 | `system:role:list` |
| `GET /system/roles/{roleId}` | 角色详情 | `system:role:view` |
| `POST /system/roles` | 创建角色 | `system:role:create` |
| `PUT /system/roles/{roleId}` | 修改名称、描述、状态 | `system:role:update` |
| `DELETE /system/roles/{roleId}` | 删除未使用的普通角色 | `system:role:delete` |
| `GET/PUT /system/roles/{roleId}/menus` | 查询/替换目录、页面和按钮授权 | `system:role:grant` |
| `GET/PUT /system/roles/{roleId}/permissions` | 查询/替换独立接口权限授权 | `system:role:grant` |
| `GET /system/roles/{roleId}/data-scope` | 查询数据范围 | `system:role:data-scope` |
| `PUT /system/roles/{roleId}/data-scope` | 设置数据范围与自定义部门 | `system:role:data-scope` |

`super_admin` 不允许删除、停用或削减固有权限。第一版角色写入及授权接口仅 `super_admin` 可执行。授权修改在一个事务内完成；后续请求直接读取 MySQL 当前权限。删除角色前检查是否仍分配给用户。

## B：部门、菜单与接口权限

| 方法与路径 | 用途 | 权限码 |
|---|---|---|
| `GET /system/depts/tree` | 部门树 | `system:dept:list` |
| `GET /system/depts/{deptId}` | 部门详情 | `system:dept:view` |
| `POST /system/depts` | 创建部门 | `system:dept:create` |
| `PUT /system/depts/{deptId}` | 修改部门、排序或父级 | `system:dept:update` |
| `DELETE /system/depts/{deptId}` | 删除空部门 | `system:dept:delete` |
| `GET /system/menus/tree` | 目录、页面、按钮树 | `system:menu:list` |
| `GET /system/menus/{menuId}` | 菜单详情 | `system:menu:view` |
| `POST /system/menus` | 创建目录、页面或按钮 | `system:menu:create` |
| `PUT /system/menus/{menuId}` | 编辑菜单 | `system:menu:update` |
| `DELETE /system/menus/{menuId}` | 删除无引用菜单 | `system:menu:delete` |
| `GET /system/permissions` | 分页查询独立接口权限 | `system:permission:list` |
| `GET /system/permissions/{permissionId}` | 接口权限详情 | `system:permission:view` |
| `POST /system/permissions` | 新增接口权限 | `system:permission:create` |
| `PUT /system/permissions/{permissionId}` | 编辑接口权限 | `system:permission:update` |
| `DELETE /system/permissions/{permissionId}` | 删除无引用接口权限 | `system:permission:delete` |

`/system/menus/tree` 是菜单管理树，包含 `CATALOG`、`MENU`、`BUTTON`、`EMBEDDED`、`LINK`；`/menu/all` 是当前用户的路由树，包含目录、页面、内嵌和外链。独立 API 权限由 `/system/permissions` 管理。写入仅允许 `super_admin`；菜单移动须校验无环，页面组件只能引用已注册视图。

## C：会话与审计

| 方法与路径 | 用途 | 权限码 |
|---|---|---|
| `GET /auth/sessions` | 当前用户自己的在线会话 | 已登录 |
| `DELETE /auth/sessions/{sessionId}` | 撤销自己的指定会话 | 已登录，仅本人 |
| `GET /system/sessions` | 管理员分页查看在线会话 | `system:session:list` |
| `DELETE /system/sessions/{sessionId}` | 管理员强制下线 | `system:session:revoke` |
| `GET /system/login-logs` | 分页查询登录日志 | `system:login-log:list` |
| `GET /system/operation-logs` | 分页查询操作日志 | `system:operation-log:list` |

管理菜单按“系统管理 → 日志管理 → 登录日志 / 操作日志”组织；页面源码位于 `frontend/apps/web-antdv-next/src/views/system/log/`。日志接口路径保持不变。

日志接口只读，支持分页、账号精确匹配、结果或操作类型、带时区的 ISO 8601 时间范围筛选（服务端换算为北京时间），按权限码及当前用户的数据范围限制可见内容，不返回密码、完整令牌或敏感请求体。未知账号的失败登录记录仅具有 `ALL` 数据范围的授权用户可见。会话撤销应立即影响刷新操作；Access Token 是否立即失效按[核心接口设计](10-核心接口设计.md)的会话检查规则实现。

在线会话只展示未撤销且未过期的记录，管理员按账号精确筛选；本人会话接口只访问本人数据，并标记当前会话。非超级管理员不能强制下线超级管理员。个人中心已接入本人会话列表和撤销操作。

## D：按需扩展，不作为第一批后端工程的阻塞项

字典管理已落地，接口与规则见[字典管理](19-字典管理.md)。图片上传已落地为 `POST /upload`，详见[后端运行说明](../backend/README.md)。下表列出尚未确定的扩展能力。

| 能力 | 建议接口方向 | 启用前需完成 |
|---|---|---|
| 系统参数 | `/system/configs` | 参数分级、敏感配置存储规则 |
| 通用文件管理 | `/files` 查询、下载、管理 | 元数据、访问控制、安全扫描 |
| 仪表盘 | `/dashboard/summary` | 真实业务指标定义 |

这些接口不能只因模板目录预留了 `admin-system` 就提前写空实现。确定需求后增加 Flyway 迁移、DTO、权限码和 OpenAPI 定义。

## 通用接口规则

- 管理列表统一 `page`（从 1 开始）、`pageSize`，响应 `data: {items: [], total: 0}`；列表排序字段通过后端白名单映射。
- 创建、编辑、停用和授权操作返回明确成功结果；资源 ID 从查询接口取得。请求 DTO 不直接暴露数据库实体。
- 批量授权使用 `PUT` 原子替换，避免前端逐条增删产生中间不一致状态。
- `system:*` 权限码登记在 `sys_menu.auth_code` 或 `sys_permission.permission_code`，角色分别通过 `sys_role_menu`、`sys_role_permission` 获得；按钮显示与后端接口校验使用同一码。
- 管理接口对 `super_admin`、当前用户自己的角色/状态/会话等敏感目标增加业务规则，避免误锁唯一管理员。
- A、B、C 批次共同维护[同一个 OpenAPI 文件](openapi/核心接口.openapi.json)；B 批次另有[详细契约](12-权限管理接口详细设计.md)。
