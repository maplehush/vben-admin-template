## 当前状态

- 已确定：单租户、模块化单体、MySQL 8.4、Redis、用户多角色、菜单/按钮/API/数据权限。
- 已确定：数据库名 `maple_hush_admin`；本地只需建空库，表由 Flyway 迁移创建。第一版权限决策读取 MySQL，不缓存授权结果。
- 当前前端基线：已下载的 Vben Admin 5 `apps/web-antdv-next`；用户、角色、部门、菜单、接口权限、在线会话和审计日志管理页面已按真实接口接入。个人中心已接入本人资料、改密和会话管理。正式登录页去除演示账号与公开注册，增加服务端图片验证码。
- 前端工作区已收敛为 `apps/web-antdv-next` 和它实际依赖的共享包；其余 UI 应用、Nitro Mock 与上游文档站已移除。`playground/` 保留作源码参考，不参与模板构建。精简范围与保留目录见[前端精简与配置](18-前端精简与配置.md)。
- 已确定：仅预置 `super_admin` 角色；首次管理员账号通过一次性初始化命令创建。本机已初始化 `admin` 用户。
- 已完成后端基础：模块化单体工程、配置、Flyway V1–V14 和一次性管理员初始化。`local` Profile 管理个人电脑的连接配置，`dev` 留给共享开发环境。当前数据库迁移以 `backend/schema/` 为准；本机开发库的实时版本需在该库查询 `flyway_schema_history`。详见[后端运行说明](../backend/README.md)。
- 已完成认证与首屏接口：服务端图片验证码、登录、刷新和退出；Bearer Token 验证、会话状态检查、首次改密限制、本人改密、用户信息、权限码和已打包页面的菜单读取。关键路径已通过自动测试和本机联调。
- 已完成前端登录接入：`web-antdv-next` 登录页使用服务端图片验证码，移除演示账号、滑块和公开注册入口；首次改密页与守卫、后端菜单模式、Refresh Token 刷新和本地代理已接通。类型检查和生产构建通过。
- 已完成权限管理后端：用户、角色、部门、菜单和接口权限的查询及管理写入；服务端执行权限与数据范围校验。
- 已完成前端用户、角色、部门、菜单、接口权限和字典管理页面：真实接口、分页、权限按钮、用户角色分配、角色授权、数据范围配置及部门与菜单树维护。当前菜单构建还包含在线会话和两类审计日志页面。前端类型检查、生产构建和后端测试通过。
- 已完成在线会话管理：本人查询与撤销会话，管理员分页查询与强制下线；Flyway V3 增加在线会话菜单及两条权限资源。强制下线立即使 Access Token 和 Refresh Token 失效，非超级管理员不能下线超级管理员。V9 增加登录日志、操作日志菜单及独立接口权限，V10 将它们归入“系统管理 → 日志管理”，两类日志查询按角色权限和数据范围过滤。
- [菜单与权限拆分架构](15-菜单与权限拆分架构.md)已经落地：V1–V3 的 `sys_resource` 是历史设计，V4 分出菜单/按钮、独立接口权限及两类角色授权，V5 修正菜单查询/详情权限码。
- 已完成图片上传接口与 OSS 适配、字典后端分页和操作审计。隔离 MySQL 8.4 集成测试已验证 V9→V14 迁移、权限边界和字典审计；运行方式见[后端运行说明](../backend/README.md)。
- 待验收：完整浏览器登录、首次改密及系统管理操作联调。工作台的统计和项目仍为明确标注的示例数据。
- 待确定：生产部署环境、迁移账号与应用账号分离方案；系统参数、通用文件管理及真实业务仪表盘按业务需求再设计。
