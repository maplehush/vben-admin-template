# 前后端接口约定

以下以已下载的 Vben Admin 5 `apps/web-antdv-next` 为前端基线。它与 `apps/web-antd` 当前的认证、用户信息和菜单 API 文件相同，请求适配器主要差别为 UI 提示组件。切换其他应用时，重新核对 `src/api` 和请求适配器。前端 `/api` 代理是否去除前缀由部署配置决定，Spring Controller 不应同时实现两套路径。

验证码、登录、刷新、用户信息、权限码和动态菜单的详细字段、状态码与示例见[核心接口设计](10-核心接口设计.md)。
模板全部计划接口及实施批次见[后端接口全景](11-接口全景与实施批次.md)。
用户、角色、部门、资源及授权的详细字段见[权限管理接口设计](12-权限管理接口详细设计.md)。

## 接口文档与协作流程

Spring Boot Controller 和 DTO 是接口契约的代码来源，springdoc 生成 OpenAPI JSON。团队在 **Apifox** 中通过文件或受控 URL 导入这份 OpenAPI，管理接口讨论、环境、调试与协作。后端实现改动后重新生成并同步，避免 Apifox 与代码长期分叉。Apifox 中的测试用例和环境配置由团队维护；OpenAPI 导入主要同步接口与数据模型。

Knife4j 是本地接口文档 UI 的候选增强，不是生成契约的唯一来源，也不取代 Apifox。其官方快速开始目前只列出 Spring Boot 2/3，且 starter 内含 springdoc；在本模板使用的 Spring Boot 4.1.x 上，须先以最小工程验证启动、`/v3/api-docs` 和页面可用性，再决定是否加入，避免重复引入 springdoc 依赖。

## 核心接口

| 方法与路径 | 用途 | 响应 `data` |
|---|---|---|
| `GET /auth/captcha` | 获取一次性图片验证码 | `{ "captchaId": "...", "imageData": "data:image/png;base64,...", "expiresInSeconds": 120 }` |
| `POST /auth/login` | 账号、密码和验证码登录 | `{ "accessToken": "..." }` |
| `POST /auth/refresh` | 使用 Cookie 刷新令牌 | 特例：原始响应体为新 Access Token 字符串 |
| `POST /auth/logout` | 退出并撤销会话 | 空值或空字符串 |
| `GET /user/info` | 当前用户信息 | `userId`、`username`、`realName`、`roles`、`homePath` 等 |
| `GET /auth/codes` | 当前用户权限码 | 字符串数组 |
| `GET /menu/all` | 当前用户菜单 | Vben 路由对象数组 |
| `POST /upload` | 登录用户上传图片（multipart 的 `file` 字段） | `{ "key": "vben-admin-img/...", "url": "https://..." }` |

普通接口成功响应统一为 `{ "code": 0, "data": ..., "message": "ok" }`。错误响应使用非零业务码，并给出可读 `message`；HTTP 401 表示未认证，403 表示已认证但无权。当前前端 `refreshTokenApi` 使用基础请求客户端并直接读取 `response.data`，仓库 Mock 返回原始 token 字符串，因此刷新接口是响应包装的特例。若改为统一包装，需同步修改前端适配器并测试自动刷新流程。

前端请求在 `Authorization` 中发送 Bearer Token，并发送 `Accept-Language`。刷新与退出请求带凭据 Cookie。

登录页仅展示账号、密码、图片验证码三个输入项，另有“记住账号”勾选项和登录按钮；验证码输入框与图片同行等高，图片可点击刷新。不保留滑块、“看不清”、“忘记密码”或自助注册、演示账号选择、手机号/扫码、第三方登录入口。`captchaId` 是前端自动附带的不可见挑战标识，不是第四个输入项。验证码只用于账号密码登录，不要求刷新令牌时再次输入。前端“记住账号”只在登录成功后保存用户名。

## 动态菜单对象

```json
{
  "name": "SystemUser",
  "path": "/system/user",
  "component": "/system/user/list",
  "meta": {
    "title": "system.user.title",
    "icon": "carbon:user"
  }
}
```

目录和页面可含 `children`、`redirect`。`component` 不带 `views/` 前缀和 `.vue` 后缀，必须与前端实际视图对应。按钮和 API 资源不进入该数组。启用后端动态路由时，前端设置 `accessMode: 'backend'`。

## 列表与管理接口

用户、角色管理列表使用分页参数 `page`、`pageSize`，分页数据为 `{ "items": [...], "total": 0 }`；部门、菜单管理使用树查询，接口权限管理使用分页查询。字段已固定在[唯一 OpenAPI 文件](openapi/核心接口.openapi.json)，前端页面接入时按此契约适配。写入接口使用请求 DTO 校验；路径、权限码和状态值不接受未校验的自由输入。
